## ทำอะไรได้บ้าง (สรุป)

**ตัดให้อัตโนมัติ**
- ตัด **ช่วงเงียบ** และ **เสียงหายใจ** ระหว่างประโยค ปรับได้ว่าจะตัดแบบนุ่ม ปกติ หรือรัว
- ถอดคำพูดเป็น **ข้อความภาษาไทย** ด้วย Whisper ที่รันในเครื่อง แล้วไฮไลต์จุดที่ **พูดผิด พูดซ้ำ หรือคำเติม** (อ่า เอ่อ อืม) ให้ตัดจากข้อความได้เลย
- ต่อ **หลายคลิปชนกัน** เป็นไฟล์เดียว และเตือนเมื่อเจอ **เทคที่อัดพลาด** แล้วอัดใหม่
- ใช้ **หลายแทร็กเสียงพร้อมกัน** (เช่น ไมค์ + เสียงเกม + เพลงจาก OBS) ปรับความดังแยกแต่ละแทร็กได้

**ทำให้พร้อมลง**
- **ซับไทยอัตโนมัติ** แบบ TikTok (คำที่กำลังพูดเป็นสีเหลือง) หรือแบบ YouTube พร้อมไฟล์ `.srt` แก้คำผิดได้
- ส่งออกเป็น **YouTube 16:9** หรือ **TikTok / Shorts 9:16** (ครอปตามคน หรือภาพเต็มกับพื้นหลังเบลอ)
- **เสียงพากย์ใส** (ลดเสียงรบกวน ลดเสียง ส/ซ เกลี่ยเสียง) และปรับความดังเป็นมาตรฐาน −14 LUFS
- **ซูมสลับตรงรอยต่อ** ช่วยกลบรอยตัด
- **ปี๊บคำหยาบ** ให้เอง (แก้รายการคำได้)
- **✨ ทำ Shorts** จากคลิปยาว: หาช่วงเด็ด แล้วส่งออกเป็นคลิปแนวตั้งพร้อมซับและหัวข้อ
- **Chapters** สำหรับคำอธิบายคลิป YouTube

**ใช้กับโปรแกรมอื่น**
- ส่งไทม์ไลน์ที่ตัดแล้วไปตัดต่อต่อใน **Premiere Pro** หรือ **DaVinci Resolve** ได้ โดยไม่ต้องเรนเดอร์
- **OBS อัดเสร็จแล้วเด้งถาม** ว่าจะเอาคลิปเข้าโปรแกรมไหม
- **อัปเดตตัวเอง** เมื่อมีเวอร์ชันใหม่

## ติดตั้ง

1. ไปที่ [หน้าดาวน์โหลด](https://github.com/xAomSK/katchon/releases/latest) แล้วกดไฟล์ **`JumpCut-Setup-x.y.z.exe`** (ในหัวข้อ Assets)
2. ดับเบิลคลิกไฟล์ที่โหลดมา แอปจะติดตั้งให้เองโดยไม่ต้องใช้สิทธิ์แอดมิน แล้วมีไอคอน **คัทชน** บนเดสก์ท็อปกับเมนู Start
3. ถ้า Windows ขึ้น **“Windows protected your PC”** ให้กด **More info → Run anyway** (แอปยังไม่ได้เซ็นชื่อดิจิทัล)

- ffmpeg ติดมากับแอปแล้ว ไม่ต้องลงเพิ่ม
- เมื่อมีเวอร์ชันใหม่ แอปจะโหลดให้เองเบื้องหลัง แล้วติดตั้งตอนปิดโปรแกรม (ดู [อัปเดตตัวเอง](#16-อัปเดตตัวเอง))

## เริ่มใช้ใน 5 ขั้น

1. **ลากไฟล์วิดีโอ** มาวางในหน้าต่าง (ลากหลายไฟล์พร้อมกันได้ แอปเรียงตามเวลาที่อัดให้)
2. แอปตัดช่วงเงียบให้ทันที บนไทม์ไลน์ **สีเขียว = เก็บไว้**, **สีแดง = ตัดออก** ถ้าตัดเยอะหรือน้อยไป ให้เลือก **นุ่ม / ปกติ / รัว** ทางขวา
3. กด **📝 ถอดคำพูด** ครั้งแรกแอปจะชวนติดตั้งส่วนถอดคำพูด (โหลดครั้งเดียว 3–5 GB) จากนั้นจุดที่น่าจะพูดผิดจะขึ้นเป็นไฮไลต์สีส้ม
4. กด **F** ไล่ดูทีละจุด ถ้าใช่ก็กด **X** เพื่อตัด
5. กด **ส่งออก** แล้วเลือกรูปแบบ **YouTube** หรือ **TikTok / Shorts**

แอปบันทึกงานเองตลอด ปิดแล้วเปิดใหม่ก็ทำต่อได้ ไฟล์ต้นฉบับไม่ถูกแก้ไข แอปสร้างไฟล์ใหม่ทุกครั้ง

## คู่มือทุกฟีเจอร์

หน้าจอแบ่งเป็น 4 ส่วน: **รายการคลิป** ทางซ้าย, **พรีวิว** ตรงกลาง, **ตั้งค่า** ทางขวา และ **ไทม์ไลน์** ด้านล่าง (รูปคลื่นเสียง + แถบคำพูด)

### 1. เพิ่มคลิปและจัดลำดับ

- **ลากไฟล์มาวาง** ในหน้าต่าง หรือกด **＋ เพิ่มคลิป** (Ctrl+O) เลือกได้หลายไฟล์ รองรับ MP4, MKV, MOV, M4V, WebM, AVI, FLV, TS, WMV, MPG
- คลิปเรียงตามชื่อไฟล์ ซึ่งไฟล์จาก OBS ชื่อเป็นวันเวลาที่อัด จึงเรียงตามลำดับที่อัดพอดี
- คลิปทั้งหมดจะถูก **ต่อกันตามลำดับในรายการ** ตอนส่งออก
  - **▲ ▼** เลื่อนลำดับ · **✕** เอาออกจากรายการ (ไฟล์ไม่ถูกลบ)
  - **ช่องติ๊ก** = ใช้คลิปนี้ในวิดีโอไหม เอาติ๊กออกเพื่อข้ามคลิปนั้น (เช่น เทคที่พูดผิด)
- ใต้ชื่อคลิปแสดง ความยาวเดิม → ความยาวหลังตัด, จำนวนรอยต่อ, สถานะการถอดคำพูด และแถบเล็ก ๆ บอกว่าส่วนไหนถูกเก็บ (เขียว) หรือตัด (แดง)
- ด้านบนสุดแสดงผลรวมทุกคลิป เช่น “3 คลิป · 12:40 → 9:05 (สั้นลง 3:35)”
- **งานใหม่** = ล้างรายการเพื่อเริ่มวิดีโอใหม่ · **↶ ↷** = ย้อน / ทำซ้ำ (ทุกอย่างที่แก้ ย้อนได้)

### 2. ตัดช่วงเงียบอัตโนมัติ

แอปฟังเสียงทุก 10 มิลลิวินาที แล้วตัดช่วงที่เบากว่าเส้นที่กำหนดและนานพอ ค่าในแผงขวาใช้กับทุกคลิป

| ค่า | ความหมาย |
|---|---|
| **นุ่ม / ปกติ / รัว** | ค่าสำเร็จรูป “รัว” ตัดถี่ที่สุด ช่วงเงียบเหลือสั้นที่สุด |
| **ระดับเสียงที่นับว่า “พูด”** | เส้นประสีเหลืองบนรูปคลื่น เสียงที่เบากว่าเส้นนี้ถือว่าเงียบ กด **อัตโนมัติ** ให้แอปคำนวณจากคลิป |
| **ตัดเมื่อเงียบนานเกิน** | เงียบสั้นกว่านี้ไม่ตัด (จังหวะหายใจสั้น ๆ ยังอยู่) |
| **เผื่อก่อนเริ่มพูด / หลังพูดจบ** | เว้นขอบไว้ ไม่ให้ตัดชิดคำจนเสียงขาด |
| **เสียงสั้นกว่านี้ไม่นับ** | เสียงคลิก/ป๊อปสั้น ๆ ไม่นับเป็นเสียงพูด |

- **ใช้กับคลิปนี้** ปิดได้ทีละคลิป (เช่น คลิปเกมเพลย์ที่ไม่อยากให้ตัด)
- คลิปที่แทบไม่มีเสียง แอปจะไม่ตัดอัตโนมัติ เก็บไว้ทั้งคลิป
- **หลายแทร็กเสียงพร้อมกัน**: ถ้าไฟล์มีหลายแทร็ก (เช่น OBS แยกไมค์ เสียงเกม เพลง) จะมีกล่อง **แทร็กเสียงในคลิปนี้** ทางขวา
  - **ติ๊ก** = ใส่แทร็กนั้นในวิดีโอ (ใส่ได้หลายแทร็กพร้อมกัน) · **แถบเลื่อน** = ความดังของแทร็กนั้น (0–100%) เช่น ลดเสียงเกมเหลือ 40%
  - **🎤** = แทร็กที่แอปใช้หาช่วงเงียบและถอดคำพูด เลือกแทร็กที่มีแต่เสียงไมค์จะตัดแม่นที่สุด (ไม่ต้องเป็นแทร็กที่ใส่ในวิดีโอก็ได้ เช่น OBS แทร็ก 1 = เสียงรวม, แทร็ก 2 = ไมค์อย่างเดียว)
  - พรีวิวได้ยินทุกแทร็กที่ติ๊กพร้อมกันตามความดังที่ตั้ง · **เสียงพากย์ใส** ทำกับแทร็ก 🎤 อย่างเดียว เสียงเกม/เพลงไม่โดนกรอง
  - ในรายการคลิปจะบอกว่าใช้กี่แทร็ก เช่น “เสียง 2/3 แทร็ก”
- แผงสถิติบอก ความยาวเดิม, หลังตัด, ตัดออกกี่ %, จำนวนรอยต่อ, เสียงหายใจที่ตัด และจำนวนครั้งที่แก้เอง

### 3. ตัดเสียงหายใจ

- เปิด **ตัดเสียงหายใจด้วย** ไว้ตั้งแต่แรก แอปแยกเสียงหายใจออกจากเสียงพูดด้วยลักษณะของเสียง แล้วตัดออกพร้อมช่วงเงียบ แม้จะดังเกินเส้นสีเหลือง
- เสียงหายใจเป็น **สีม่วง** บนรูปคลื่น
- อยากเก็บเสียงหายใจไหนไว้ ให้ลากเลือกช่วงนั้นแล้วกด **R**
- เสียงสั้น ๆ ที่อยู่ติดคำทั้งสองข้าง (มักเป็นเสียง ส ฉ ฟ ในคำ) แอปจะไม่ตัด

### 4. ตัดและเก็บเองบนไทม์ไลน์

- **คลิก** = ไปที่ตำแหน่งนั้น · **ลาก** = เลือกช่วง (ลากขอบช่วงที่เลือกเพื่อปรับได้, Shift+คลิก = ขยายช่วง)
- **X** (หรือ Delete) = ตัดช่วงที่เลือกออก · **R** = เก็บช่วงที่เลือกไว้ (ใช้คืนส่วนที่แอปตัดไป)
- **ดับเบิลคลิกที่ช่วง** = สลับตัด/เก็บทั้งช่วงนั้นทีเดียว
- **I / O** ระหว่างเล่น = ตั้งจุดเริ่ม / จุดจบของช่วงตรงตำแหน่งที่เล่นอยู่
- **Ctrl+ล้อเมาส์** หรือปุ่ม **－ ＋** = ซูม · **พอดีจอ** (0) · ล้อเมาส์เฉย ๆ = เลื่อนซ้ายขวา
- **ล้างที่ตัด/คืนเองในคลิปนี้** = เอาการแก้เองทั้งหมดของคลิปนั้นออก กลับไปใช้แค่การตัดอัตโนมัติ

### 5. พรีวิวและฟังรอยต่อ

- **เล่นแบบตัดแล้ว** (P) = เล่นข้ามช่วงที่ตัด และไหลต่อไปคลิปถัดไป เหมือนไฟล์ที่จะได้จริง ปิดได้ถ้าอยากฟังของเดิม
- **↓ / ↑** = กระโดดไปก่อนรอยต่อถัดไป / ก่อนหน้า 1 วินาทีแล้วเล่นให้ฟัง ไล่ฟังรอยต่อได้เร็ว
- เวลาใต้ปุ่มเล่นบอกทั้งตำแหน่งในคลิป และตำแหน่งในวิดีโอที่ต่อแล้ว
- **พรีวิวลื่น**: แอปทำไฟล์พรีวิวขนาดเล็กให้แต่ละคลิปเบื้องหลัง (ดูความคืบหน้าในรายการคลิป) เสร็จแล้วสลับไปใช้เอง กรอและข้ามรอยตัดได้ทันที และเปิดไฟล์ที่เล่นตรง ๆ ไม่ได้ (เช่น MKV, HEVC) ได้ด้วย
- พรีวิวแสดงผลแบบเดียวกับตอนส่งออก: **ซับ** ขึ้นบนภาพ, **ซูมสลับ** เห็นจริง, **เสียงปี๊บ** ได้ยินจริง
- **🎧 เลือกลำโพง/หูฟัง**: ปุ่มข้างแถบเสียง เลือกได้ว่าจะฟังพรีวิว (รวมเสียงปี๊บ) ผ่านอุปกรณ์ไหน เช่น หูฟังหรือ audio interface แม้ค่าเริ่มต้นของ Windows จะเป็นลำโพงจอ แอปจำไว้ให้ ถ้าถอดหูฟังออก จะเล่นที่ค่าเริ่มต้นของ Windows ไปก่อน (ปุ่มเป็นสีเหลือง) แล้วสลับกลับเองเมื่อเสียบใหม่ · ไม่มีผลกับไฟล์ที่ส่งออก
- **▯ 9:16** (V) = แสดงกรอบแนวตั้งบนภาพ ลากกรอบซ้าย-ขวาให้คนอยู่กลางกรอบ ตั้งแยกได้ทีละคลิป (ใช้ตอนส่งออก TikTok / Shorts)

### 6. ถอดคำพูดและหาจุดพูดผิด

**ติดตั้งครั้งแรก**: กด **📝 ถอดคำพูด** หรือปุ่ม **ติดตั้งส่วนถอดคำพูด** ทางขวา แอปจะบอกขนาดก่อน แล้วโหลด Python, faster-whisper และโมเดล Whisper large-v3 มาไว้ในโฟลเดอร์ของแอปเอง (ไม่ต้องใช้สิทธิ์แอดมิน ไม่ยุ่งกับโปรแกรมอื่น)
- มีการ์ดจอ NVIDIA: โหลดประมาณ 4.6 GB ใช้พื้นที่ 5.5 GB คลิป 6 นาทีถอดเสร็จราว 1–2 นาที
- ไม่มีการ์ดจอ NVIDIA: โหลดประมาณ 3.2 GB ใช้ CPU ช้ากว่า (คลิป 1 นาทีราว 3–5 นาที)
- ระหว่างติดตั้งซ่อนหน้าต่างแล้วทำงานอื่นต่อได้ หยุดกลางทางแล้วกดใหม่จะโหลดต่อจากเดิม

**แถบคำพูด** ใต้รูปคลื่นเสียง
- แอปถอดคำพูดทุกคลิปให้เอง (ปิดได้ที่ **ถอดคำพูดทุกคลิปอัตโนมัติ**) ถอดครั้งเดียว แอปจำไว้ เปิดใหม่ไม่ต้องรอ
- ซูมเข้าจนเห็นทีละคำ (ซูมออกจะเห็นเป็นประโยค เอาเมาส์ชี้จะเห็นประโยคเต็ม)
- **คลิกคำ** = ไปที่คำนั้น · **ลากผ่านหลายคำ** = เลือกหลายคำ แล้วกด **X** เพื่อตัด (แอปขยับขอบไปที่จุดเงียบที่สุดใกล้ ๆ ให้เสียงไม่ขาดกลางคำ)
- คำที่ถูกตัดแล้วเป็นสีจางมีขีดฆ่า

**ไฮไลต์สีส้ม = จุดที่น่าจะพูดผิด** แอปหาให้ 3 แบบ
- **พูดซ้ำ / เริ่มประโยคใหม่** เช่น “วันนี้เราจะมา… วันนี้เราจะมาพูดถึง…” แอปไฮไลต์อันแรกที่พูดไม่จบ แล้วเก็บอันหลังไว้
- **คำเติม** อ่า / อ่ะ / เอ่อ / อืม (ถ้า “อ่ะ” เป็นคำลงท้ายประโยค เช่น “ใช่อ่ะ” จะไม่นับ)
- คำว่า **“เอาใหม่”** ที่พูดตอนจะเริ่มเทคใหม่

**ไล่ตัด**: กด **F** (หรือปุ่ม **⚠ N จุดน่าตัด**) แอปจะซูม เลือกจุดนั้น และเล่นให้ฟังตั้งแต่ก่อนหน้า 1 วินาที ถ้าใช่ก็กด **X** · **Shift+F** = จุดก่อนหน้า · ปุ่ม **✂ ตัดที่ไฮไลต์ทั้งหมด** = ตัดทุกจุดในคลิปนี้ทีเดียว (Ctrl+Z ครั้งเดียวย้อนได้หมด)
- **ถอดคำพูดคลิปนี้ใหม่** ใช้เมื่อผลที่ถอดได้ดูแปลก ๆ

### 7. ซับไตเติล

ซับมาจากคำพูดที่ถอดไว้ และตามจุดตัดเสมอ คำที่ตัดทิ้งจะไม่ขึ้นในซับ
- เลือกแบบซับทางขวา หัวข้อ **ซับไตเติล · คำหยาบ**
  - **TikTok**: ตัวใหญ่ทีละ 2–4 คำ คำที่กำลังพูดเป็นสีเหลือง
  - **YouTube**: ทีละบรรทัดด้านล่างจอ
  - **ไม่ใส่**
- ซับขึ้นบนพรีวิวทันที ขนาดและตำแหน่งเหมือนในไฟล์ที่ส่งออก (ถ้าเปิดกรอบ 9:16 ซับจะอยู่ในกรอบ)
- **ฟอนต์ซับ** เลือกจากฟอนต์ไทยที่มีในเครื่อง (เช่น Sukhumvit Set, Leelawadee UI) ฟอนต์ถูกฝังไปตอนเรนเดอร์
- **แก้คำผิด**: ซูมเข้าจนเห็นทีละคำ แล้ว **ดับเบิลคลิกคำ** พิมพ์คำที่ถูกแล้วกด Enter (Esc = ยกเลิก, ลบให้ว่าง = ไม่แสดงคำนั้น) คำที่แก้แล้วเป็นสีฟ้า แก้แค่ในซับ ไม่ได้ตัดเสียง
- ภาษาอังกฤษในประโยคไทยจะมีเว้นวรรคให้อ่านง่าย (“เรื่อง Roblox กัน”)
- ตอนส่งออกได้ทั้ง **ฝังในวิดีโอ** และ **ไฟล์ .srt** แยก (อัปโหลดเข้า YouTube หรือลากเข้า Premiere/Resolve ได้)

### 8. ปี๊บคำหยาบ

- เปิด **ดูดเสียงคำหยาบ (ปี๊บ)** ทางขวา (เปิดไว้ตั้งแต่แรก) แอปหาคำหยาบจากคำพูดที่ถอดไว้ แล้วขึ้นแถบ **สีชมพู** บนแถบคำพูด พร้อมบอกจำนวนที่เจอในคลิปนี้
- ตอนพรีวิวจะได้ยินเสียงปี๊บ ในไฟล์ที่ส่งออกเสียงช่วงนั้นถูกแทนด้วยเสียงปี๊บ และในซับคำนั้นเป็น `***`
- **ปี๊บเอง / เลิกปี๊บ**: เลือกคำหรือช่วงแล้วกด **B** (หรือปุ่ม 🔇 ปี๊บ) ใช้ได้แม้ไม่ได้ถอดคำพูด
- **แก้รายการคำ** ที่ **⚙ ตั้งค่า → คำหยาบที่จะปี๊บ** ใส่ `=` หน้าคำถ้าจะปี๊บเฉพาะตอนพูดคำนั้นเดี่ยว ๆ (เช่น `=ห่า` จะไม่ปี๊บ “ห่าง”) · คำว่า มึง/กู ไม่อยู่ในรายการเริ่มต้น
- ปี๊บมีผลกับไฟล์ที่แอปเรนเดอร์ ไทม์ไลน์ Premiere/Resolve ใช้เสียงต้นฉบับ

### 9. จับเทคที่อัดซ้ำ

ถ้าพูดพลาดแล้วกดอัดใหม่เป็นไฟล์ใหม่ แอปเทียบคำพูดของคลิปที่ติดกัน แล้วขึ้นป้าย **⚠** ในรายการคลิป
- **น่าจะเป็นเทคหลุด** — ทั้งคลิปถูกพูดใหม่ในคลิปถัดไป → ปุ่ม **ไม่ใช้คลิปนี้**
- **คลิปถัดไปเริ่มพูดเรื่องเดียวกันใหม่ตั้งแต่ต้น** — เทคที่เลิกกลางทาง → ปุ่ม **ไม่ใช้คลิปนี้**
- **ท้ายคลิปนี้พูดซ้ำกับต้นคลิปถัดไป** → ปุ่ม **ตัดท้ายที่ซ้ำ**
- **คลิปสั้นมาก** (ยังไม่ได้ถอดคำพูด) — อาจเป็นเทคหลุด
- กด **ไม่ใช่** ถ้าแอปเดาผิด ป้ายจะหายไป · ทุกปุ่มย้อนได้ด้วย Ctrl+Z

### 10. ส่งออกวิดีโอ (YouTube / TikTok)

กด **ส่งออก** → **ไฟล์วิดีโอ MP4** แล้วเลือก

**รูปแบบ** (เลือกแล้วแอปตั้งค่าที่เหมาะกับแพลตฟอร์มนั้นให้ เปลี่ยนเองได้ทุกอย่าง)

| รูปแบบ | ขนาด | ค่าที่ตั้งให้ | ชื่อไฟล์ |
|---|---|---|---|
| **เหมือนต้นฉบับ** | เท่าคลิปแรก | — | `<ชื่อคลิป>_cut.mp4` |
| **YouTube 16:9** | 16:9 (เช่น 1920×1080) | เสียงพากย์ใส, ซูมสลับ 105%, ไฟล์ .srt | `<ชื่อคลิป>_youtube.mp4` |
| **TikTok / Shorts 9:16** | 1080×1920 | ซับแบบ TikTok, ซูมสลับ 110%, เสียงพากย์ใส | `<ชื่อคลิป>_tiktok.mp4` |

- **จัดภาพแนวตั้ง** (เฉพาะ 9:16): **ครอปเฉพาะคน** (ใช้กรอบที่เลื่อนไว้ในพรีวิว) หรือ **ภาพเต็ม + พื้นหลังเบลอ** (ย่อภาพทั้งจอไว้กลาง เติมพื้นหลังด้วยภาพเดียวกันแบบเบลอ เหมาะกับคลิปอัดจอ)
- **ซับไตเติลในวิดีโอ**: ไม่ใส่ / แบบ TikTok / แบบ YouTube
- **ซูมสลับตรงรอยต่อ**: ไม่ซูม / 105% / 110% / 115% / 120% — ท่อนเว้นท่อนจะซูมเข้าเล็กน้อย ช่วยกลบรอยตัด
- **เสียงพากย์ใส**: ตัดเสียงทุ้มต่ำ ลดเสียงรบกวน ลดเสียง ส/ซ ที่บาดหู บีบเสียงให้สม่ำเสมอ และเพิ่มความชัด
- **ปรับความดังเป็น −14 LUFS** (มาตรฐาน YouTube/TikTok) เปิดให้เองเมื่อเลือก YouTube, TikTok หรือเสียงพากย์ใส
- **คุณภาพ**: สูง (แนะนำสำหรับอัปโหลด) / กลาง / ไฟล์เล็ก · **ตัวเข้ารหัส**: อัตโนมัติ / การ์ดจอ NVIDIA (เร็วมาก) / CPU
- **บันทึกไฟล์ซับ .srt คู่กันด้วย**
- ปี๊บคำหยาบใส่ให้เองตามที่ตั้งไว้
- คลิปที่ขนาดภาพหรือ fps ไม่เท่ากัน แอปปรับให้เท่ากันเอง · ภาพกับเสียงตรงกันทุกเฟรม รอยต่อเสียงมี fade สั้น ๆ ไม่มีเสียงคลิก
- ระหว่างส่งออกเห็นความคืบหน้า ความเร็ว และเวลาที่เหลือ กดหยุดได้ เสร็จแล้วกดเปิดไฟล์หรือเปิดโฟลเดอร์ได้เลย

### 11. ส่งไปตัดต่อต่อใน Premiere Pro / DaVinci Resolve

แอปบันทึกแค่ “ไทม์ไลน์” ที่ชี้ไปที่ไฟล์ต้นฉบับ ไม่ต้องเรนเดอร์ เสร็จทันที แต่ละท่อนเป็นคลิปแยก ดึงขอบคืนหรือขยับได้ทุกจุด

**Premiere Pro** (`.xml`)
1. หน้าส่งออกเลือก **ไทม์ไลน์ Premiere Pro** แล้วกด **บันทึกไทม์ไลน์**
2. ใน Premiere กด **File → Import…** (Ctrl+I) เลือกไฟล์ `.xml`
3. แผง Project จะมี Sequence ชื่อเดียวกับไฟล์ ดับเบิลคลิกเพื่อเปิด
- ภาพกับเสียงของแต่ละท่อนผูกกันไว้ ทุกแทร็กเสียงที่ติ๊กไว้ในแอปมาเป็นแทร็กของตัวเองใน Premiere (ความดังที่ตั้งในแอปไม่ตามไป ปรับต่อใน Premiere ได้)

**DaVinci Resolve** (`.fcpxml`)
1. หน้าส่งออกเลือก **ไทม์ไลน์ DaVinci Resolve** แล้วกด **บันทึกไทม์ไลน์**
2. ใน Resolve กด **File → Import → Timeline…** เลือกไฟล์ แล้วติ๊ก **Automatically import source clips into media pool**

ทั้งสองแบบได้ไฟล์ `.srt` คู่กันด้วยถ้าติ๊กไว้ · อย่าย้ายหรือเปลี่ยนชื่อไฟล์ต้นฉบับหลังบันทึก เพราะไทม์ไลน์ชี้ไปที่ไฟล์เดิม

### 12. ✨ ทำ Shorts จากคลิปยาว

กด **✨ ทำ Shorts** ด้านบน (ต้องถอดคำพูดก่อน) ใช้จากวิดีโอที่ตัดแล้ว ทุกคลิปที่ติ๊กไว้
1. เลือก **จำนวน** (3 / 5 / 8) และ **ความยาวแต่ละคลิป** (15–30 / 20–60 / 45–90 วิ) แล้วกด **หาช่วงที่น่าทำ**
   - ไม่ใช้ AI: แอปหาช่วงที่ขึ้นต้นด้วยคำดึงคนดู (ทำไม / รู้ไหม / แบน / ล่าสุด / ไม่น่าเชื่อ…) พูดกระชับ และไม่ใช่ช่วงเปิด-ปิดคลิป
   - ติ๊ก **ให้ AI (Claude) เลือก** (ต้องใส่ API key): AI อ่านทั้งคลิป เลือกช่วงที่มี hook ดูรู้เรื่องในตัวเอง ตั้งหัวข้อ และบอกเหตุผล
   - ทุกช่วงตัดตรงต้นประโยคและท้ายประโยคพอดี ไม่ซ้อนกัน มีดาวบอกคะแนน
2. แต่ละช่วงกด **▶ ดู** เพื่อดูในพรีวิว (เล่นจบช่วงแล้วหยุดเอง) แก้ **หัวข้อ** ที่จะขึ้นด้านบนคลิปได้ เอาติ๊กออกถ้าไม่เอา
3. เลือก **จัดภาพ** (ครอปเฉพาะคน / ภาพเต็ม + พื้นหลังเบลอ), **ซับ** (TikTok / ทีละบรรทัด / ไม่ใส่) และ **ใส่หัวข้อด้านบน** แล้วกด **ส่งออกที่เลือก**
- ได้ไฟล์ 1080×1920 พร้อมซับ หัวข้อ ซูมสลับ เสียงพากย์ใส ปี๊บคำหยาบ และความดัง −14 LUFS ในโฟลเดอร์ `<ชื่อคลิปแรก>_Shorts` ข้างคลิปต้นฉบับ
- ตำแหน่งครอปใช้ตามกรอบ 9:16 ที่เลื่อนไว้ในพรีวิวของแต่ละคลิป

### 13. Chapters สำหรับ YouTube

กด **📑 Chapters** ด้านบน
- **สร้างอัตโนมัติ**: แบ่งตามคำขึ้นหัวข้อใหม่ (“ต่อไป” “อย่างแรก” “สุดท้าย” …) และจุดเริ่มแต่ละคลิป ตั้งชื่อจากประโยคแรกของช่วง
- **✨ ให้ AI แบ่งและตั้งชื่อ** (ต้องใส่ API key): AI อ่านทั้งคลิปแล้วแบ่งตามหัวข้อจริง ตั้งชื่อสั้น ๆ ให้คนดูหาส่วนที่สนใจเจอ
- แก้ **เวลา** (นาที:วินาที) และ **ชื่อ** ได้ในรายการ · **▶** = ไปดูช่วงนั้น · **✕** = ลบ · **＋ เพิ่มช่วงที่ตำแหน่งที่เล่นอยู่**
- แอปเตือนถ้าผิดกฎของ YouTube (ต้องมี 3 ช่วงขึ้นไป ช่วงแรกเริ่ม 0:00 แต่ละช่วงยาว 10 วินาทีขึ้นไป)
- กด **คัดลอก** แล้ววางในคำอธิบายคลิป YouTube ได้เลย
- เวลาผูกกับเนื้อหา ไม่ใช่ตัวเลข ถ้าไปแก้จุดตัดทีหลัง เวลาของ Chapters จะขยับตามเอง

### 14. OBS: อัดเสร็จแล้วเด้งถาม

- ตอนเปิดคัทชนไว้ พอ OBS อัดเสร็จ จะมีหน้าต่าง **🎬 อัดเสร็จแล้ว** ให้เลือก **เพิ่มเข้างานนี้**, **เริ่มงานใหม่ด้วยคลิปนี้** หรือ **ไม่เอา**
- ถ้าอัดหลายไฟล์ติดกัน จะรวมให้เลือกในหน้าต่างเดียว คลิปที่สั้นกว่า 3 วินาทีจะไม่ติ๊กไว้ (มักเป็นการกดอัดพลาด) และคลิปสั้นกว่า 15 วินาทีมีคำเตือน
- ถ้าหน้าต่างคัทชนไม่ได้อยู่ข้างหน้า จะมีแจ้งเตือนของ Windows คลิกแล้วกลับมาที่แอป
- แอปอ่านโฟลเดอร์ที่ OBS บันทึกไฟล์จากการตั้งค่าของ OBS เอง และรอจน OBS เขียนไฟล์เสร็จจริงก่อนถาม
- ตั้งค่าได้ที่ **⚙ ตั้งค่า → OBS**: เปิด/ปิดการถาม, เลือกโฟลเดอร์เอง, **กดปิดหน้าต่างแล้วให้ทำงานต่อที่ถาด** (ไอคอน ✂ ข้างนาฬิกา คลิกขวาเพื่อปิดโปรแกรมจริง), **เปิดพร้อม Windows แบบซ่อนไว้ที่ถาด**

### 15. AI (Claude) — ไม่ใส่ก็ได้

ใช้กับ **✨ ให้ AI แบ่งและตั้งชื่อ** (Chapters) และ **ให้ AI เลือก** (Shorts) เท่านั้น นอกนั้นทำในเครื่องทั้งหมด ไม่ใส่ก็ใช้ทุกอย่างได้
1. เข้า **console.anthropic.com** → เติมเครดิต → สร้าง API key
2. ใน **⚙ ตั้งค่า → AI (Claude)** วาง key แล้วกด **บันทึก** แอปเช็กว่า key ใช้ได้ก่อน แล้วเก็บแบบเข้ารหัสในเครื่อง (กด **ลบ key** เมื่อเลิกใช้)
- ส่งไปแค่ข้อความที่ถอดจากคลิป ไม่ส่งวิดีโอหรือเสียง ใช้โมเดล Claude Opus 5.5 คิดเงินตามการใช้ ปกติไม่กี่บาทต่อครั้ง

### 16. อัปเดตตัวเอง

## เครื่องที่ใช้ได้

- Windows 10 หรือ 11 แบบ 64-bit
- การ์ดจอ NVIDIA ไม่บังคับ แต่ถ้ามี จะเรนเดอร์และถอดคำพูดเร็วขึ้นมาก (ไม่มีก็ใช้ CPU ได้ แค่ช้ากว่า)
- พื้นที่ว่าง: ตัวแอปประมาณ 850 MB และถ้าติดตั้งส่วนถอดคำพูด ใช้อีก 3.4–5.5 GB ไฟล์พรีวิวใช้ได้ถึง 8 GB (ลบอันเก่าเอง)
- ใช้อินเทอร์เน็ตแค่ตอนติดตั้งส่วนถอดคำพูด ตอนอัปเดต และตอนใช้ AI (ถ้าเปิดใช้)

## ความเป็นส่วนตัวและข้อมูลที่แอปเก็บ

- การตัด ถอดคำพูด และเรนเดอร์ ทำในเครื่องทั้งหมด วิดีโอไม่ถูกส่งไปไหน
- ฟีเจอร์ AI (ไม่บังคับ) ส่งไปแค่ข้อความที่ถอดได้ เมื่อใส่ API key เองเท่านั้น
- ไฟล์ต้นฉบับไม่ถูกแก้ไข
- ข้อมูลของแอปอยู่ที่ `%APPDATA%\jumpcut-app`: งานที่ทำค้าง, ระดับเสียงที่วิเคราะห์ไว้, ผลถอดคำพูด, ไฟล์พรีวิว (`proxies`), ส่วนถอดคำพูด (`python`, `models`) และ API key ที่เข้ารหัสไว้ ลบโฟลเดอร์นี้ได้ถ้าเลิกใช้

## ถามบ่อย

**ไม่มีการ์ดจอ NVIDIA ใช้ได้ไหม?**
ได้ครบทุกอย่าง แต่การถอดคำพูดจะช้ากว่ามาก (คลิป 1 นาทีใช้ราว 3–5 นาที) และเรนเดอร์ด้วย CPU

**ถอดคำพูดผิดบางคำ**
Whisper อาจฟังชื่อเฉพาะหรือคำแสลงผิดบ้าง ดับเบิลคลิกคำเพื่อแก้ในซับได้ ถ้าผิดเยอะผิดปกติ ลอง **ถอดคำพูดคลิปนี้ใหม่**

**Premiere ขึ้น File Import Failure**
ย้ายไฟล์ `.xml` ไปไว้ในโฟลเดอร์ที่ชื่อไม่มีอีโมจิ (เช่น 🔴) แล้ว Import ใหม่ · ถ้าขึ้นว่าหาไฟล์ไม่เจอ (Link Media) แปลว่าไฟล์ต้นฉบับถูกย้ายหรือเปลี่ยนชื่อ

**ถอนการติดตั้ง**
Settings → Apps → **คัทชน** แล้วลบ `%APPDATA%\jumpcut-app` ถ้าไม่อยากเก็บข้อมูลไว้
